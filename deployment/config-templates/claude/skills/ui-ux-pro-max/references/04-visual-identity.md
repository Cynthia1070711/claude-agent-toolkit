## 5 Visual Design Philosophies(canvas-design L55-74)

每個 philosophy 是 4-6 段藝術運動宣言,引導視覺執行:

### 1. **Concrete Poetry**(具體詩)
> 「Communication through monumental form and bold geometry.」

巨大色塊 + 雕塑型字體(超大單字,微小標籤)+ Brutalist 空間分割 + Polish poster meets Le Corbusier。文字是稀有有力的姿態。

### 2. **Chromatic Language**(色彩語言)
> 「Color as the primary information system.」

幾何精度,色彩區域創造意義。字體最小化(小無襯線標籤)。Josef Albers' interaction meets data viz。

### 3. **Analog Meditation**(類比冥想)
> 「Quiet visual contemplation through texture and breathing room.」

紙張紋理 + 墨水暈染 + 大量留白。攝影 / 插畫主導,字體耳語(小、克制)。日本攝影集美學。

### 4. **Organic Systems**(有機系統)
> 「Natural clustering and modular growth patterns.」

圓潤形 + 有機排列 + 自然色彩 through architecture。資訊以視覺圖表 / 空間關係 / 圖示表達。

### 5. **Geometric Silence**(幾何靜默)
> 「Pure order and restraint.」

Grid-based 精度 + 大膽攝影 / 圖形 + 戲劇性負空間。Swiss formalism meets Brutalist material honesty。

## 5 Algorithmic Philosophies(algorithmic-art L57-74)

生成藝術 / p5.js / 程序化設計用:

| Philosophy | 視覺表達 |
|---|---|
| **Organic Turbulence** | Flow fields driven by layered Perlin noise. 千千粒子沿向量場流動,軌跡累積成有機密度圖 |
| **Quantum Harmonics** | Grid 上粒子,相位通過 sin 波演化。近粒子相位干涉(constructive/destructive)→ 浮現曼陀羅 |
| **Recursive Whispers** | 分支結構遞迴細分。Golden ratio 約束,L-system 樹形 |
| **Field Dynamics** | 向量場由數學函數或 noise 構成。粒子從邊緣生,沿場線流動,在邊界 / 平衡點死亡 |
| **Stochastic Crystallization** | 隨機 circle packing 或 Voronoi 細分。Cells 透過 relaxation 演化 |

## Brand Consistency

LOGO 規範:
- Clear space ≥ LOGO 高度 1x
- Min size: 24px height(web)/ 12mm(print)
- 變體: Full / Mark / Wordmark / Mono / Reversed
- 禁止: 拉伸 / 改色 / 加陰影 / 旋轉

Voice & Tone:
- 友善 vs 專業 vs 權威(選一)
- 一致跨 product copy / email / notification / error message
- Don't: 一頁友善另一頁冷硬
