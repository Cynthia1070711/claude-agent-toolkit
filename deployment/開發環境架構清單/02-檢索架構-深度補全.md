### 3.1.4 內部 symbol_index + 融合排序（S_final 完整實作）

**融合公式**（`pre-prompt-rag.js` L129-L134 實作）：
```
S_final = α·vec + β·graph + γ·fts + δ·centrality
```

| 權重 | 來源 | 計算方式 | 數值 |
|------|------|----------|------|
| `α` (ALPHA) | 向量相似度 | ONNX 本地 embedding (Xenova/all-MiniLM-L6-v2) cosine similarity | **0.6** |
| `β` (BETA) | 依賴圖相似度 | `symbol_dependencies` 2-hop 展開 × `RELATION_WEIGHTS` 加權 | **0.2** |
| `γ` (GAMMA) | FTS5 文字相似度 | FTS5 trigram 全文比對正規化 | **0.2** |
| `δ` (DELTA) | 中心性 | `PHYCOOL_PPR_ENABLED=true` 時走 **Personalized PageRank**；否則靜態 `god_nodes` centrality | **0.05** |

**RELATION_WEIGHTS**（`pre-prompt-rag.js` L152-L157，SSoT 需同步 `compute-centrality.cjs`）：
```javascript
const RELATION_WEIGHTS = {
  inherits: 1.0,
  implements: 0.9,
  calls: 0.7,
  uses_inferred: 0.4,
};
```

**三層 Fallback (CMI-10 Hybrid Fusion)**：
```
ONNX 向量 (主路徑) 
    ↓ 失敗
Hybrid (FTS5 + 向量 RRF 融合) 
    ↓ 失敗
LIKE (純文字比對，搜尋 symbol_index.code_snippet)
```
任一層失敗自動降級，**不中斷**使用者提問。

**Personalized PageRank (G14 P2)**：
- 啟用：`PHYCOOL_PPR_ENABLED=true`
- 實作：`repomap-ppr.cjs` / `buildSymbolMeta` / `computePersonalizedPageRank`
- Seeds：向量搜尋命中的 top-N 符號
- Fail-safe：PPR 失敗 fallback 靜態 centrality，注入量不增（只 rerank）

### 3.2.3 分層降級機制（bwu-11，`pre-prompt-rag.js` L183-L241, L1468-L1488）

**丟棄優先序** (`LAYER_DROP_ORDER`) —— 判準：「Claude 能否自行重新取得」：
```javascript
['doc', 'code', 'lsp', 'instinct', 'session', 'skill', 'pipeline']
```

**必留層**（永不進入丟棄候選）：`violation`, `task`, `idd`, `godNodes`
理由：皆為 Claude 無法自行得知的 DB 內部狀態、紀律歷史或故意設計禁令。

**自取管道** (`LAYER_RECOVERY`) —— 降級時把「內容」換成「指標」：
```javascript
doc: 'search_documents / Grep'
code: 'codegraph_context / Grep'
lsp: 'dotnet build / npx tsc --noEmit'
instinct: 'search_instincts'
session: 'search_context({category:"session"})'
skill: '.claude/skills/skills_list.md'
pipeline: 'search_worker_runs'
```

**降級演算法** (`degradeInjectionLayers`)：依優先序丟棄可自取回的層，直到總長度 ≤ `MAX_INJECT_CHARS`。若必留層合計仍超過上限，如實回傳並標記 `overflow: true`。

**降級告警** (`formatDegradeNotice`)：三管道共用同一句（stderr debug log / systemMessage 使用者顯示 / additionalContext Claude 可見），附上自取管道。
