### 3.1 三引擎職能分工

三套引擎**不是重複建設**，各自回答不同問題：

| 引擎 | 回答的問題 | 資料結構 | 何時用 |
|------|-----------|---------|--------|
| **CodeGraph** | 「我需要知道什麼？」 | tree-sitter AST → SQLite 圖 | 改 code 前取上下文、查符號定義、追呼叫鏈 |
| **GitNexus** | 「改了會影響什麼？」 | LadybugDB 圖 + 執行流 | 評估 blast radius、commit 前驗證、rename |
| **內部 symbol_index** | （後台）「哪些最相關？」 | SQLite + 向量 + PageRank | 服務 RAG Layer 3/4，不直接呼叫 |

**標準修改流程**：
```
1. codegraph_context      取上下文（「這塊是怎麼運作的」）
2. gitnexus_impact        看 blast radius（「動了會炸到誰」）
3. HIGH/CRITICAL → gitnexus_context 補查
4. 動工
5. gitnexus_detect_changes 驗證變更範圍符合預期
```

#### 內部 symbol_index + 融合排序

融合公式（`pre-prompt-rag.js` 實作）：

```
S_final = α·vec + β·graph + γ·fts + δ·centrality
```

- `vec` — ONNX 本地 embedding 語意相似度
- `graph` — `symbol_dependencies` 2-hop 展開 × `RELATION_WEIGHTS` 加權
- `fts` — FTS5 全文比對
- `centrality` — `PHYCOOL_PPR_ENABLED=true` 時走 **Personalized PageRank**（相對當前任務重排，`repomap-ppr.cjs`）；否則走靜態 `god_nodes` centrality

三層 fallback（CMI-10 Hybrid Fusion）：`ONNX 向量 → Hybrid → LIKE`，任一層失敗自動降級不中斷。

### 3.2 ★ 12 層 RAG 注入逐層說明

`.claude/hooks/pre-prompt-rag.js` 掛在 **UserPromptSubmit**，每則 prompt 自動注入。
**這是整個環境的心臟** —— 讓 AI「一開口就已經知道專案脈絡」。

| Layer | 內容 | 字元預算 | 環境變數開關 | 觸發條件 |
|:----:|------|-------:|-------------|---------|
| **1** | Session 記憶（最近 3 次對話摘要） | 2,400 | — | 恆常 |
| **2** | 相關技術債 | （併入 L3 區塊） | — | 關鍵字命中 |
| **3** | 任務感知 / Story 進度 | 550 | — | 恆常 |
| **4** | **Code RAG**（相關符號源碼） | 1,450 | — | intent=code |
| **5** | Document RAG（相關專案文檔） | 650 | — | 關鍵字命中 |
| **6** | 歷史決策 | （併入 L3 區塊） | — | 關鍵字命中 |
| **7** | Pipeline State（進行中的 checkpoint 警告） | 300 | — | 有 active pipeline |
| **8** | Skill 推薦（機械式關鍵字匹配） | 400 | — | 恆常 |
| **9** | LSP 編譯錯誤診斷 | 750 | — | intent=code |
| **10** | **IDD 故意設計**（禁違反清單） | 1,400 | `PHYCOOL_IDD_INJECT` | intent=code |
| **11** | **違規熱區**（最近 30 天） | 650 | `PHYCOOL_VIOLATION_INJECT_ENABLED` | 恆常 |
| **12** | **ECC 直覺**（採納分數過濾後；2026-08-15 起另讀 Gemini 常駐 agent 預計算 `agent-precompute.json`，消費 `PHYCOOL_INSTINCT_AGENT_CONSUME` 預設 off = shadow 只記對照，詳 §7 深度補全 §7.12.10） | （見 `inject-budget.cjs`） | `PHYCOOL_INSTINCT_INJECT` | intent=code |

**設計要點**：
- **字元預算硬上限**：各層獨立預算，總和不超過 `MAX_INJECT_CHARS`，避免注入吃掉對話空間
- **fail-open**：任一層查詢失敗僅該層停用（stderr 告警），**絕不阻塞使用者提問**
- **cascade 降級**：Layer 11 超預算時候選數 5→3→1 逐級縮減
- **intent 判定**：非 code 類提問跳過 Layer 4/9/10/12，省 token

**Subagent 另有獨立路徑**：`.claude/hooks/subagent-context-inject.js` 在 SubagentStart 注入（Phase 4.5），
因為 subagent 不經過 UserPromptSubmit。

### 3.3 檢索維運與重建閉環

| 場景 | 工具 |
|------|------|
| **一鍵全量重建** | `node .context-db/scripts/refresh-all-retrieval.cjs`（orchestrator，編排下列所有 wrapper） |
| 含 GitNexus 重建 | `refresh-all-retrieval.cjs --with-gitnexus` |
| 破壞前預演 | `--dry-run` |
| 並行防呆 | `retrieval-lock.cjs`（防兩個視窗同時重建） |
| 符號採集 | `harvest-codegraph-to-symbolgraph.cjs`（CodeGraph → symbol_index） |
| 依賴推導 | `infer-uses-deps.js` |
| 中心性計算 | `compute-centrality.cjs`（god_nodes） |
| PageRank | `repomap-ppr.cjs` |
| 向量生成 | `generate-embeddings.js` / `incremental-embed.js` / `backfill-doc-embeddings.js` |
| 文檔索引 | `scan-doc-index.js` / `import-documents.js` / `sync-documents.js`（結尾自動 spawn backfill 補新/變 chunk 缺向量，2026-08-15；勿再建議「sync 後跑 import」— checksum 已更新必 skip） |
| **健康偵測** | `.claude/hooks/retrieval-health-advisor.js`（SessionStart，偵測 staleness 並提示，不阻斷） |
| 架構驗證 | `verify-retrieval-architecture.cjs` |
| 文檔數字同步 | `sync-retrieval-doc-counters.cjs`（校正文檔中的統計數字） |

**閉環**：
```
   code 變更 ──▶ CodeGraph 檔案監看（~500ms）──▶ nodes/edges 更新
        │                                              │
        │                                              ▼
        │                              harvest-codegraph-to-symbolgraph
        │                                              │
        │                                              ▼
        │                              symbol_index + symbol_dependencies
        │                                              │
        │                          ┌───────────────────┤
        │                          ▼                   ▼
        │                 compute-centrality      incremental-embed
        │                          │                   │
        │                          ▼                   ▼
        │                    god_nodes           symbol_embeddings
        │                          └─────────┬─────────┘
        │                                    ▼
        │                        S_final 融合排序（Layer 4）
        │                                    │
        └───────────── 下次 prompt 自動注入 ◀─┘

   SessionStart: retrieval-health-advisor 偵測落後 → 提示 refresh-all-retrieval.cjs
```
