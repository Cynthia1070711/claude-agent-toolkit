### 9.4 業務內容禁入與脫敏（2026-08-08 修訂）

**產品業務資訊一律不進打包** —— 不是脫敏成佔位（佔位等於還原時填回，仍保留業務結構），
而是就地代換為通用假值，或整檔排除。詳見深度補全版 §9.4。

| 項目 | 處理 | 打包後應為 |
|------|------|:---------:|
| 前台方案帳號 / 後台 RBAC 帳號 / 測試密碼 | → 代換為 `user1@example.com` / `example.local` / `ExamplePw123` | 0 |
| `src/` 業務程式碼路徑 | → 代換為 `src/YourApp/...` | 0 |
| 維運者 Email / Git 帳號 | → 代換為 `dev@example.com` / `your-git-user` | 0 |
| 內容主體即業務資訊的 Skill / Rule | → 不列入白名單（5 Skill + `canvas-layout-invariants.md`） | 0 |
| 專案絕對路徑 | → `${PROJECT_ROOT}` / `${USER_HOME}`，由 `install-devenv.cjs` 依使用者路徑還原 | 佔位 |
| API Key / PAT | → 不打包 `.mcp.json`，只給 `mcp.json.template` | 0 |

**機械閘門**：`node scripts/verify-package-sanitization.cjs` —— 獨立於打包腳本複驗，
非 0 命中不得推送開源。

## §10 異機部署還原順序

```powershell
# ── 1. 前置需求 ──
# Node.js 20+ / .NET 8 SDK / PowerShell 7+ / Git / Docker（僅 github MCP 需要）

# ── 2. 依賴安裝 ──
cd .context-db          ; pnpm install
cd ../tools/dev-console ; npm install
cd ../../.context-db/symbol-indexer ; dotnet build -c Release

# ── 3. 記憶庫建空庫 ──
node .context-db/scripts/init-db.js
Get-ChildItem .context-db/migrations/*.sql |
  Where-Object { $_.Name -notlike '*-down.sql' } |
  ForEach-Object { node .context-db/scripts/apply-migration.js $_.FullName }

# ── 4. 設定檔 ──
Copy-Item .claude/mcp_config.example.json .mcp.json
#   → 填入 GITHUB_PAT / CONTEXT7_API_KEY（建議設為 User-level 環境變數）
Copy-Item .claude/settings.local.json.example .claude/settings.local.json
az login                                       # 若使用 azure MCP

# ── 5. 建立檢索索引 ──
npx codegraph init -i
npx gitnexus analyze
node .context-db/scripts/refresh-all-retrieval.cjs

# ── 6. 匯入既有對話歷史（選用）──
node .context-db/scripts/import-conversations.js --full

# ── 7. 安裝 BMAD 本體後，套用 bmad-overlay/ 覆蓋層 ──

# ── 8. 驗證 ──
node scripts/verify-deployment-docs.cjs
node .context-db/scripts/verify-retrieval-architecture.cjs
node .context-db/scripts/validate-server.js
cd tools/dev-console ; npm run dev            # 開 http://localhost:5174 確認 22 頁面
```
