### 5.2 Skill 生命週期閉環

```
   需求出現
      │
      ├─ 通用工具？ ──▶ Skill(skill="skill-builder") Mode A
      └─ SaaS 模組？ ─▶ Skill(skill="saas-to-skill") Mode A
      │
      ▼
   產出 SKILL.md（frontmatter: name / description / 觸發關鍵字）
      │
      ▼
   同步 skills_list.md 索引 ◀── skill-index-drift-detector.js 監控
      │
      ▼
   使用：Layer 8 關鍵字匹配自動推薦 ／ 使用者 /skill-name 呼叫
      │
      ▼
   Code 變更 ──▶ skill-sync-gate.md 觸發 ──▶ Mode B 更新（8 面向驗證）
      │           FileChanged: skill-change-detector.js 產生影響報告
      ▼
   規模過大 ──▶ skill-creation-discipline.md ──▶ 拆分或 Progressive Disclosure
      │
      ▼
   不再使用 ──▶ RETIRED 標記（保留目錄，cross-ref-discipline 清理引用）
```

**強制紀律**：修改任何 `SKILL.md` **必先字面呼叫** `Skill(skill="skill-builder")` 或
`Skill(skill="saas-to-skill")`，直接 Edit 會被 `skill-tool-invocation-guard.js` 攔截。
