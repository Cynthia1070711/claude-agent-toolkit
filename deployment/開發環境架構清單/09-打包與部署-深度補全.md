**已知非殘留（勿誤判）**：
- `AccountKey=` 等 Azure 樣式在 `cross-ref-precheck.js` / `pre-commit-quality.js` /
  `verify-deployment-docs.cjs` 共 4 處，是 **secret detector 自己的偵測正則**，不是憑證。

## 10 異機部署還原順序 (實測可執行)

> **使用者的專案路徑與名稱人人不同**，本包不假設任何一種：
> 範本中的路徑一律為 `${PROJECT_ROOT}` / `${USER_HOME}` 佔位，
> 由 `install-devenv.cjs` 依 `--project-root` 參數還原。
> **沒有這一步，`settings.json` 的 hook 指令會是字面的 `cd "${PROJECT_ROOT}"`，67 個掛載點全數失效。**

```powershell
# ── 1. 前置需求 ──
# Node.js 20+ / .NET 8 SDK / PowerShell 7+ / Git / Docker（僅 github MCP 需要）

# ── 2. ★ 還原配置到你的專案路徑（先 dry-run 預覽）──
node scripts/install-devenv.cjs --project-root "D:/Work/my-project"
#   → 確認「佔位還原」區段的 ${PROJECT_ROOT} / ${USER_HOME} 值正確後：
node scripts/install-devenv.cjs --project-root "D:/Work/my-project" --apply
#   可選：--project-name（預設取目錄名）· --user-home（預設 os.homedir()）
#   目標端已有同名檔且內容不同時預設不覆蓋，確認後加 --force
#
#   這一步會還原：.claude/{rules,agents,commands,hooks,skills,settings.json}
#                 .context-db/{server.js,scripts,migrations,tests}
#                 tools/dev-console · scripts/ · CLAUDE.md 等範本

# ── 3. 依賴安裝 ──
cd .context-db          ; pnpm install
cd ../tools/dev-console ; npm install
cd ../../.context-db/symbol-indexer ; dotnet build -c Release

# ── 4. 記憶庫建空庫 ──
node .context-db/scripts/init-db.js
Get-ChildItem .context-db/migrations/*.sql |
  Where-Object { $_.Name -notlike '*-down.sql' } |
  ForEach-Object { node .context-db/scripts/apply-migration.js $_.FullName }

# ── 5. 個人設定檔（不在打包內，需自填）──
Copy-Item .claude/mcp_config.example.json .mcp.json
#   → 填入 GITHUB_PAT / CONTEXT7_API_KEY（建議設為 User-level 環境變數）
az login                                       # 若使用 azure MCP

# ── 6. 建立檢索索引 ──
npx codegraph init -i
npx gitnexus analyze
node .context-db/scripts/refresh-all-retrieval.cjs

# ── 7. 安裝 BMAD 本體後，重跑 install 套用覆蓋層 ──
# 先依 BMAD 官方指南安裝，_bmad/ 存在後重跑步驟 2 即會套用 bmad-overlay/

# ── 8. 驗證 ──
node scripts/verify-deployment-docs.cjs
node .context-db/scripts/verify-retrieval-architecture.cjs
node .context-db/scripts/validate-server.js
cd tools/dev-console ; npm run dev            # 開 http://localhost:5174 確認 22 頁面
```
