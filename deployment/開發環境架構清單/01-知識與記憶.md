### 2.4 ★ 對話紀錄保留機制（完整閉環）

這是本環境**最容易被忽略但最有價值**的機制：Claude Code 的對話不會隨視窗關閉而消失。

#### 資料來源與寫入路徑（實測追溯）

| 階段 | 執行者 | 觸發時機 | 動作 |
|------|--------|---------|------|
| **1. 即時記錄** | `.claude/hooks/pre-prompt-rag.js` | UserPromptSubmit | `INSERT INTO conversation_turns`（role=user） |
| **2. 回合快照** | `.context-db/scripts/log-session.js` | Stop / SessionEnd / PreCompact | `INSERT conversation_turns`（assistant turn 含 `tools_used`/`files_touched`，2026-08-15 起）+ UPSERT `conversation_sessions`（2 分鐘內 UPDATE，逾時 INSERT） |
| **3. 歷史補全** | `.context-db/scripts/import-conversations.js` | 手動 / 排程 | 掃描 `~/.claude/projects/{專案雜湊}/*.jsonl` 原生 transcript，冪等重建（`--full` 全量 / 預設增量） |
| **4. 向量化** | `.context-db/scripts/incremental-embed.js` | Stop | 新對話寫入 `conversation_embeddings` |
| **5. 時區修正** | `.context-db/scripts/fix-timezone.js` | 維運 | 統一為 offset-aware `+08:00` |

> 註：`.context-db/scripts/log-turn.js` 為獨立即時記錄腳本（CMI-3，目標延遲 <50ms），
> **實測未掛載於 settings.json**（零註冊零 require 殭屍）—— 其職能已被 `pre-prompt-rag.js` 內建的 INSERT 取代。
> 打包時可保留為備用，但不需註冊。其宣稱的「tools_used/files_touched 由 Stop Hook 事後處理」
> 從未存在，2026-08-15 已由 `turn-extract.js` 修復（log-session.js 就地萃取 transcript 檔尾）。

#### 檢索與回注路徑

| 用途 | 途徑 |
|------|------|
| AI 主動查歷史對話 | MCP `search_conversations` / `get_session_detail` / `list_sessions` |
| **自動回注新視窗** | `pre-prompt-rag.js` Layer 1 → 每次 prompt 注入最近 3 個 session 摘要（預算 2400 字元） |
| 跨軌訊息帶對話上下文 | `ctrl-channel-inject.js` 讀 `conversation_turns` |
| Context 用量監控 | `context-budget-monitor.js` 讀 `token_estimate` 累計 |
| 人工檢視 | DevConsole `/sessions` |

#### 閉環圖

```
   使用者 prompt ──▶ pre-prompt-rag.js ──┬──▶ INSERT conversation_turns
                          │              └──▶ Layer 1 注入最近 3 session ──┐
                          │                                                │
                          ▼                                                │
                    AI 工作 / 回應                                          │
                          │                                                │
                          ▼                                                │
              Stop: log-session.js ──▶ conversation_sessions 快照           │
                          │                                                │
                          ▼                                                │
            Stop: incremental-embed.js ──▶ conversation_embeddings          │
                          │                                                │
                          ▼                                                │
              search_conversations（AI 主動查）                             │
              DevConsole /sessions（人工查）                                │
                          │                                                │
                          └────────── 下一次對話 ◀──────────────────────────┘

   旁路補全：~/.claude/projects/*.jsonl ──▶ import-conversations.js ──▶ 同上
```

**實測驗證**：`conversation_turns` 最新一筆時間戳與當前對話同步（誤差 < 1 秒），機制運作中。
