## 5.2 Skill 生命週期閉環（含實際腳本、Hook、驗證機制）

### 5.2.1 完整生命週期流程圖

```
需求出現
    │
    ├─ 通用工具？ ──▶ Skill(skill="skill-builder") Mode A
    └─ SaaS 模組？ ─▶ Skill(skill="saas-to-skill") Mode A
    │
    ▼
產出 SKILL.md（frontmatter 必含: name / description / 觸發關鍵字 / version / last-synced-epic）
    │
    ▼
同步 skills_list.md 索引 ◀── skill-index-drift-detector.js 監控 (FileChanged hook)
    │
    ▼
使用：Layer 8 關鍵字匹配自動推薦 (pre-prompt-rag.js) ／ 使用者 /skill-name 呼叫
    │
    ▼
Code 變更 ──▶ skill-sync-gate.md 觸發 ──▶ Mode B 更新（8 面向驗證）
    │           FileChanged: skill-change-detector.js 產生影響報告
    ▼
規模過大 ──▶ skill-creation-discipline.md ──▶ 拆分或 Progressive Disclosure
    │
    ▼
不再使用 ──▶ RETIRED 標記（保留目錄，cross-ref-discipline 清理引用）
```

### 5.2.2 關鍵強制紀律（實測驗證）

| 紀律 | 強制機制 | 違反後果 |
|------|----------|----------|
| 修改任何 `SKILL.md` **必先字面呼叫** `Skill(skill="skill-builder")` 或 `Skill(skill="saas-to-skill")` | `skill-tool-invocation-guard.js` (PreToolUse) | 直接 Edit 會被攔截 BLOCK |
| 新增/更名/刪除 Skill 必同步 `skills_list.md` | `skill-index-drift-detector.js` (PostToolUse) | Layer 8 推薦失效、索引漂移報告 |
| Skill 規模超標 (建議 < 500 行) | `skill-creation-discipline.md` | 強制拆分或 Progressive Disclosure |
| 退役 Skill 保留目錄但標記 RETIRED | `cross-ref-discipline.md` | 清理所有引用，防僵屍檔 |

### 5.2.3 8 面向驗證 (saas-to-skill Mode B)

1. **商業規則同步** —— Skill 中的業務規則與程式碼一致
2. **Schema 同步** —— DB 表結構變更同步至 Skill
3. **路由同步** —— API 路由變更同步
4. **UIUX 同步** —— 設計規範變更同步
5. **測試同步** —— 測試案例/策略同步
6. **ADR/IDD 同步** —— 架構決策/故意設計同步
7. **Hook/Rule 同步** —— 相關規範同步
8. **文檔同步** —— 相關文檔更新

const fs = require('fs');
const path = require('path');
const skillsDir = '.claude/skills';
const dirs = fs.readdirSync(skillsDir).filter(d => fs.statSync(path.join(skillsDir, d)).isDirectory());
dirs.forEach(dir => {
  const skillPath = path.join(skillsDir, dir, 'SKILL.md');
  if (fs.existsSync(skillPath)) {
    const content = fs.readFileSync(skillPath, 'utf8');
    const hasName = /^name:\s/.test(content);
    const hasDesc = /^description:\s/.test(content);
    const hasTriggers = /^trigger/.test(content);
    if (!hasName || !hasDesc || !hasTriggers) console.log('MISSING:', dir, {hasName, hasDesc, hasTriggers});
  }
});
